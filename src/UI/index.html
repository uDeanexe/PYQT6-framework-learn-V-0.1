My Framework Dasar untuk PyQt6 Free

This is a desktop application with web UI.

Keterangan & Struktur Code

Framework ini menghubungkan Python dan JavaScript menggunakan QWebChannel.

  • src/main.py: Mengatur Window utama dan konfigurasi WebEngine.
  • src/Controllers/Bridge.py: Logika backend. Fungsi di sini bisa dipanggil dari JS.
  • src/UI/: Tampilan antarmuka (HTML, CSS, JS).

Keperluan (Requirements)

Untuk menjalankan aplikasi ini, pastikan Python 3.8+ terinstall dan jalankan perintah:

pip install -r requirements.txt

Library utama: PyQt6, PyQt6-WebEngine.
